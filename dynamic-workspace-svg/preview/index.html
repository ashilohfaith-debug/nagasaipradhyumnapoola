ℹ About auto-refresh & GitHub caching

This preview page refreshes the SVG client-side every minute by appending a cache-busting query parameter (?_t=…). The serverless function itself returns Cache-Control: no-cache, no-store so your browser and direct API callers always get a fresh time.

GitHub README caching limitation

  • GitHub proxies all images in Markdown through camo, its image CDN.
  • Camo currently caches images for ~5 minutes, regardless of your Cache-Control headers. There is no documented way to bypass this.
  • Practical impact: the clock in a GitHub README will be up to 5 minutes stale for any given viewer. This is inherent to GitHub's infrastructure and is not a bug in this project.
  • For accurate real-time display, link directly to /api/workspace.svg in a browser or client that respects no-store.
